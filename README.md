# SmileFlow Suite

Prompt para generar el frontend

Crea un frontend SaaS profesional y comercializable para clínicas odontológicas, con modelo de negocio basado en implementación inicial y membresía mensual recurrente.

Objetivo

Desarrollar una plataforma modular para clínicas pequeñas, medianas, grandes y grupos odontológicos, sin limitar la cantidad de sucursales, odontólogos, empleados o pacientes. Cada clínica debe poder activar únicamente los módulos que necesita y ampliar su plan posteriormente.

Estilo visual

Diseño moderno, limpio, profesional y confiable.

Enfocado en salud, tecnología y gestión empresarial.

Colores principales: azul, blanco, celeste y verde.

Interfaz responsive para escritorio, tablet y móvil.

Componentes con bordes redondeados, sombras suaves y buena jerarquía visual.

Accesibilidad, alto contraste y navegación intuitiva.

Usar iconos relacionados con odontología, agenda, pacientes, estadísticas y configuración.

Arquitectura

Preparar la interfaz para arquitectura multiempresa.

Requisitos técnicos

Usar TypeScript.

Usar Tailwind CSS o sistema de diseño equivalente.

Crear componentes modulares.

Implementar diseño responsive.

Validar formularios.

Añadir modales, tablas, filtros, pestañas, gráficos y calendarios.

Generar un resultado listo para presentar a potenciales clientes y vender como producto SaaS.
